What the difference is for. A section header is a label, not content — its job is to be findable when you look for it and quiet when you don't. A is the same size as the values underneath it, so the header competes with the data; it reads as a heading only because it is uppercase. B and C step down, which is the conventional move and the one the surfaces built since v0.44.0 reached for on their own. The extra letter-spacing in C is what keeps 10px uppercase legible — at that size the caps run together without it, which is why the pairing is usually 10px + wider rather than 10px + wide.
